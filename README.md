# Cross-border Listing

面向跨境电商的 Listing 编写与商品图片策划技能，支持根据目标平台和国家站点组织工作。

## 工作流程

1. 从产品规格或说明书提取事实；未提供时从商品链接提取候选参数，交用户确认。
2. 研究竞品现状、热销证据、关键词与评论，明确缺失数据。
3. 编写并校验本地化标题、卖点和描述。
4. 有产品图时提供场景方案，选定后输出整套图片提示词。
5. 使用用户选择的网页或 API 渠道生成，集中审核后导出图片并保留母版。

公开页面词频不等于真实流量；未知参数不写成事实；不会自动发布商品 Listing。

## 安装与使用

将本目录放入支持 Agent Skills 的工具所使用的 skills 目录。入口为 `SKILL.md`，配套资源保留相对目录结构。Codex 中可使用 `$cross-border-listing` 调用。

提供目标平台/国家、竞品链接，以及已有的产品规格、说明书和产品图。无需提供账号密码或 API 密钥到聊天中。

`scripts/check_fields.py` 使用 Python 标准库检查字符、词数或 UTF-8 字节数。它不验证商品事实，也不保证平台接受。规则输入示例见 `references/platform-and-qa.md`。

## 数据与权限

本仓库只含通用技能规则和辅助脚本，不附带用户资料、客户产品素材、聊天记录、账号配置或凭证。实际使用时，浏览网页及生成图片取决于运行环境的可用工具和用户授权。本技能不会配置遥测或自动上传本地资料。
