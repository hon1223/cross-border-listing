# 场景选择、整套提示词与图片交付

Listing 完成且用户提供本品白底图/主图时启用。用户只要文案或提示词时按其范围停在对应交付点。这里的“整套主图”指商品图片组：区分首张商品主图与后续功能/场景附图，不把所有图片都当平台首图。

## 1. 检查本品参考图并研究类目场景

实际查看用户图，建立视觉锚点：型号/变体、轮廓比例、颜色材质、按钮/接口/灯/滤网数量和位置、商标文字、随附部件。图与已确认规格冲突只询问相关项；外观不能证明性能或认证。使用本品图约束产品，竞品图片仅研究构图与场景，不替换本品。

复用竞品研究样本，补充目标平台类目及 Google 网页/图片搜索，使用品类词加具体用途/场景词。记录搜索词、地区/语言、日期、来源链接及去重后的商品样本。优先可比且有热销信号、较高评分的链接；没有热销证据就称类目参照，不伪装筛选结果。

区分三种证据：
- 常见场景：抽样商品图片/搜索结果出现次数，报告 n/N 和抽样条件；同一商品重复结果只计一次。只代表当前样本曝光频率。
- 买家喜爱：评论明确提及的使用情境、审美或便利性，说明样本规模及措辞；高评分不是某张场景图受欢迎的证明。
- 高点击场景：有相应创意/图片 ID 的曝光、点击、CTR 和周期才可比较。商品整体点击不能归因于其中一张图，CTR 比较也要说明样本及投放条件。无此数据就写“点击偏好未验证”，推荐依据改为场景适配和公开样本。

不得声称已找到全平台“最多/最喜爱/点击最高”，除非数据确实覆盖该范围。场景须遵循产品用途、安装和使用限制，不因竞品图常见就复制不适用的做法。

## 2. 提供 2–3 个可视场景方案，等待选择

根据品类给出实质不同而合理的情境，避免所有产品套用厨房或相同豪宅背景。例如户外用品按真实使用地形/天气，收纳用品按空间与尺寸，厨电按安装和操作环境；这些只是思路，不是固定模板。

每个方案提供可查看的场景示意图/布局板或生成预览，并附：适合的买家任务、场景布置、色彩/光线、产品角度与占比、标题留白、与竞品的差异、依据链接及证据边界。不能只给三个方案名称。图板可用用户产品图与简单布局示意，不需要先调用生图服务；明确“布局示意”，不能冒充完成的生成图。

用户特别要求真实生图预览时，使用已选且可用的渠道；尚未选渠道而预览需要登录/API 时，仅将必要的渠道选择提前至此，后面复用，不能静默接入付费 API。不可生成时如实交付可视布局板并说明限制，不假装已经生成场景图。

展示 A/B/C 后请用户选一种或指定组合。等待明确选择后才完成整套提示词；等待期间可整理图片清单和规则。记录选中场景及版本，不重复审批同一选择。

## 3. 写出完整、可独立使用的图片提示词

根据品类、已确认卖点和目标平台图片规则决定张数，提出一套有分工的图片组，不硬套九张或前两张白底。先确定每张的信息任务，避免重复。首图遵循目标平台的背景、文字和构图要求；附图可用简短宣传语、功能说明、尺寸/安装、细节、配件或使用场景，但只写已确认内容。

每张必须包含以下字段，不能写“同上”而导致单独使用失去商品约束：

|字段|必需内容|
|---|---|
|ID / 用途|IMG-01 等、首图/功能/场景/尺寸，关联事实版本与事实 ID|
|参考资产|用户原图文件/附件、选中变体和场景方案；哪些结构不可变化|
|画面|真实环境、产品位置与占比、镜头角度、光线材质、色彩、留白；适用时人物动作必须合理|
|买家信息|这张要回答的顾虑、已确认卖点，禁止添加的未验证承诺|
|图片文字|目标站点语言的精确标题/短说明；首图不允许文字时写无叠字；不要让模型自编参数|
|文字样式|字体类别、层级、对齐、对比度、位置和安全边距，避免遮挡商品关键结构|
|真实性约束|不改变品牌/型号/比例/部件数量/结构/颜色，不增添未包含配件，不展示不支持功能|
|输出与后期|优先 1:1、渠道支持的最高合适原生分辨率、保留母版；最终 1600×1600 不等于模型原生支持该尺寸|

生成素材与文字层可分开：文字多、需准确尺寸线或已有图片只需加字时，使用确定性排版，减少拼写错误、结构漂移与噪点。提示词同时交付完整可见文案及排字说明，不先漏掉功能文字再整套返工。宣传语突出收益但不得超出事实。

## 4. 选择生图渠道并整套生成

整套提示词完成后，若尚无有效选择，集中问一次：
“选择 A：使用实际可用的内置浏览器打开 ChatGPT，您完成登录后由我操作创建图片；或 B：使用您指定的其他生图模型 API。”

- A：检查实际浏览器/Computer Use 能力，打开真实 ChatGPT 网页，登录由用户完成；通过网页实际可见的创建图片功能、上传本品参考图和提交提示词。不能用本地同名 imagegen 技能/API 冒充网页操作。无可用网页控制能力或会话失效时报告具体阻塞，不静默换渠道。
- B：确定服务商/模型、实际支持的参考图方式和输出规格、授权额度/预算及凭证已安全配置。复用有效配置，不让用户把 API key 发进聊天，不输出密钥。确认未知费用边界后再付费调用；已有明确预算无需逐张审批。
- 原始图片上传只针对用户选择的生成服务。参考资产丢失、渠道额度不足或费用超过授权时停止依赖步骤并报告；已有结果保留，不把失败视为完成。

按照整套提示词生成全部草稿，无需逐张等待用户批准；受页面串行能力限制可依次生成。每张下载实际原始结果，记录文件名、渠道/模型、提示词版本、参考图和生成顺序。不能用网页截图替代可下载母版而不披露，也不能把复制提示词称为完成生图。

先自检结构、品牌文字、参数、图片内文案、场景使用合理性、噪点、重复图和文件完整性；修复有问题的图片，避免整套无理由重做。展示整套联系表或可查看预览，并提供原图，集中请用户审核。用户明确要求逐张审图时才改为逐张。

## 5. 整套批准后输出 1600×1600

等待用户对当前整套版本的明确批准；选择场景或同意生图渠道不等于批准成品。若只修改部分图片，沿用未改部分的批准，只提交修改版补审。保留每张批准版本映射。

批准后用确定性图像工具导出整套 1600×1600 JPG，RGB/sRGB、合理高质量；保留可用的原始高清母版和文字分层源文件（如有）。正方形等比缩放；非正方形默认等比适配并协调补边，不拉伸产品，不擅自裁去文案或部件。插值放大不宣称新增原生细节。纯改尺寸不调用生图模型。

逐文件读取验证格式、像素尺寸、可解码、数量和批准版本；人工查看联系表确认无裁字/拉伸/漏图。交付 JPG 文件夹或 ZIP、母版位置、提示词文件和简短清单（ID、批准版本、原尺寸、导出尺寸、文件路径）。未批准或失败图片不可混入最终成品。用户明确指定其他尺寸/格式时覆盖此默认。
